THE OPERA GAME
— A REAL CHESSDIARY REPORT

By Venugopal Ramamoorthy — creator of ChessDiary

Paul Morphy vs. Duke Karl of Brunswick & Count Isouard (consulting)  ·  Paris Opera House, 1858  ·  White wins by checkmate, move 17

This is a complete ChessDiary analysis report for one of the most famous games in chess history — Paul Morphy's "Opera Game." It's public domain, so there's no account or privacy concern in using it as an example, and every number below is real: this exact game was run through ChessDiary's actual Stockfish backend and Gemini tactical-motif pipeline, the same services every imported game goes through. Nothing on this page is a mockup or a made-up example report.

One honest caveat: ChessDiary's Stockfish endpoint returns a quality label and centipawn loss for each flagged move, but it does not currently return a specific "play this instead" alternative move alongside the Stockfish numbers — that richer suggestion is only produced by the separate Gemini-based fallback path used when Stockfish itself is unreachable (see that guide). So the table below shows the real engine evaluation, quality, and tactical motif for every flagged move, but not an invented "best move" column.

4. HOW TO READ THIS REPORT

The move list

Standard algebraic notation, White and Black side by side. If notation itself is unfamiliar, see How to Read a Chess Scoresheet.

The evaluation graph

Each point is the engine's assessment after that move, in centipawns (100 = roughly one pawn's worth of advantage), from White's point of view. A rising line means White's position is improving; a falling line means Black is catching up or taking the lead. A steep jump in either direction usually lines up with a flagged move below.

Quality labels and centipawn loss

Centipawn loss is how much the evaluation swung against the player who just moved, compared to the engine's own best continuation. ChessDiary buckets that swing into five labels: best and good (0–40), inaccuracy (roughly 40–90), mistake (roughly 90–200), and blunder (200+ or a missed/allowed forced mate).

Tactical motifs

For every flagged move, Gemini identifies which recognizable pattern was at play — a fork, a pin, a hanging piece left undefended, and so on. Across enough games, this is what turns "you blunder sometimes" into "you specifically miss hanging pieces in the middlegame," which is the actual point of keeping a diary of your games instead of just playing and moving on.
