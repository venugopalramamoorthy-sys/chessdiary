PGN IMPORT VS. CHESS.COM/LICHESS SYNC: WHICH TO USE

By Venugopal Ramamoorthy — tournament chess player and creator of ChessDiary

ChessDiary has two genuinely different ways to get an online game into your library: uploading a PGN file (or pasting PGN text) one game at a time, and linking your Chess.com or Lichess account to sync your history automatically. They solve different problems, and using the wrong one for the job just means more manual work than necessary.

Here's what each actually does under the hood, and which one is worth reaching for depending on what you're trying to import.

1. PGN IMPORT — ONE GAME, FULL CONTROL

The PGN File and Paste Moves options on the Add Game screen both do the same thing: read a single game's worth of standard PGN notation — headers, move list, result — and add exactly that one game to your library. This is the right tool when you have one specific game you want to record: an export from a tournament pairing system, a game a friend sent you, or a PGN you copied from a database or analysis site that isn't tied to your Chess.com or Lichess account at all.

2. ACCOUNT SYNC — YOUR WHOLE HISTORY, ONE LINK

Linking your Chess.com or Lichess username under Import from Chess.com or Import from Lichess is a different operation entirely. Instead of reading one PGN, ChessDiary calls that platform's public API directly, using only the username you provide, and pulls your existing game history in bulk — you'll see a running import count as it works through however many games are available. Once linked, that username stays bound to your account for future imports, so you're not re-entering it every time you want to catch up on games played since the last sync.

3. WHAT SYNC GIVES YOU THAT A SINGLE PGN DOESN'T

  • Bulk history — sync pulls everything available from the platform's API in one pass, not just your most recent game, so it's the fast path for populating your library the first time you connect an account.
  • Metadata for free — synced games come with the time control (bullet, blitz, rapid, classical, or correspondence), opening name, and both players' ratings already attached, without you typing any of it in.
  • No manual export step — you never have to go find and download a PGN from Chess.com or Lichess yourself; ChessDiary talks to the API directly using the username you gave it.

4. WHEN A SINGLE PGN IMPORT IS STILL THE RIGHT CALL

Not every game lives on Chess.com or Lichess. A PGN emailed from a tournament organizer, a game recorded in a different app entirely, or a line you're studying from a database export all skip the sync system by design — account sync only ever reaches games actually played under your linked username on that specific platform. For anything outside that, PGN File or Paste Moves is the only path in, and it works exactly the same regardless of where the PGN came from.

5. UNLINKING AND RE-LINKING

If you stop wanting a platform synced — or need to switch which username is bound to your account — unlinking clears the connection without touching games already imported; they stay in your library as normal entries. Re-linking with a new username starts fresh from that account's history rather than merging the two.

6. USING BOTH TOGETHER

Most players end up using both: link Chess.com and/or Lichess once for the bulk of their online games, then use PGN import for the occasional outlier — a correspondence game from a different site, a puzzle export, or a friend's shared game. The two methods write to the same unified library, so there's no difference in how a game behaves in ChessDiary once it's in, regardless of which door it came through.

7. A WORKED EXAMPLE: THREE GAMES, THREE PATHS

Say you've just played a tournament weekend and want everything in one place by Monday night. Here's how that actually plays out across the two systems:

  • Saturday's round, paper scoresheet. Not on Chess.com or Lichess at all — photograph it and let ChessDiary's OCR extract the move list, which lands it in your library the same way a pasted PGN would, no account sync involved.
  • Sunday's blitz session, played on Lichess. If you've already linked your Lichess username, these show up automatically on the next sync with time control, opening name, and both ratings attached — no action needed beyond having linked the account at some earlier point.
  • A friend's game from a different platform, sent as a PGN file. This is the one-off case sync can't reach, since it was never played under your linked username anywhere. PGN File import handles it in one upload, exactly as it would any other PGN regardless of origin.

None of these three require thinking about "which import method is correct" in the moment — the format of what you have in hand (a photo, an already-linked account, or a standalone PGN) decides it for you.

8. A COMMON MISTAKE: RE-LINKING INSTEAD OF SYNCING

If a sync seems to be missing recent games, the instinct is often to unlink and re-link the account — but that's usually unnecessary and, per section 5 above, starts the import fresh rather than topping it up. A stalled or incomplete sync is far more often a temporary API issue on Chess.com's or Lichess's side than a broken link; retrying the sync itself (without unlinking first) resolves it in nearly every case, and keeps the games already imported untouched either way.
